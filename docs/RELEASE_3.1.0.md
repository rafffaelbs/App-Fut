# Fut v3.1.0

## Novidades
- **Mais segurança para o administrador.** Para limpar o histórico, editar uma partida, editar ou excluir um grupo e excluir uma pelada, o app agora pede confirmação: digital, PIN ou padrão do celular, ou uma senha do app (em Configurações > Segurança do Administrador).
- **Senha do app protegida.** Fica guardada de forma embaralhada (nunca em texto). Depois de 5 erros, o app espera 30 segundos.
- **"Esqueci a senha":** só redefine depois de confirmar pelo celular.
- A antiga senha fixa "0101" foi removida.

## Melhorias
- Só o administrador vê as ações de editar o histórico e o menu ⋮ do grupo.
- A nota do jogador agora considera toda a história.

## Para quem atualiza
- O Android passa a pedir a permissão de biometria (nada a mais para o usuário fazer).
- Celular sem bloqueio de tela: ative um bloqueio ou use a opção "Usar senha".
